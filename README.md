VEHICLE PARKING MANAGEMENT SYSTEM
FEATURE SET II

1. INTRODUCTION

The Vehicle Parking Management System is a simple system used to manage
vehicle parking information. It stores vehicle details, driver details,
parking slot information, vehicle entry and exit details, and payment status.

2. FEATURES

The system contains the following five features:

1. Vehicle Details
2. Driver Details
3. Parking Slot
4. Entry/Exit
5. Payment Status

3. VEHICLE DETAILS

This feature stores information about vehicles such as Vehicle ID,
Vehicle Number, Vehicle Type, Model, and Color.

4. DRIVER DETAILS

This feature stores driver information such as Driver ID, Name,
Phone Number, License Number, and Address.

5. PARKING SLOT

This feature manages parking slot information such as Slot ID,
Slot Number, Slot Type, and Slot Status.

6. ENTRY/EXIT

This feature records when a vehicle enters and exits the parking area.
It can store Entry ID, Entry Time, Exit Time, and Duration.

7. PAYMENT STATUS

This feature stores parking payment information such as Payment ID,
Amount, Payment Method, and Payment Status.

8. MAIN PROCESS

The basic process of the system is:

Start
↓
Enter Vehicle Details
↓
Enter Driver Details
↓
Check Parking Slot Availability
↓
Assign Parking Slot
↓
Record Vehicle Entry
↓
Record Vehicle Exit
↓
Calculate Parking Payment
↓
Update Payment Status
↓
Display Parking and Payment Details
↓
Stop

9. DATABASE ENTITIES

The main entities are:

- Vehicle
- Driver
- Parking_Slot
- Entry_Exit
- Payment_Status

10. OBJECTIVE

The main objective of this system is to maintain parking information
in an organized way and make vehicle entry, exit, parking slot,
and payment management easier.

11. TECHNOLOGY

This project can be implemented using:
- Database: MySQL
- Front End: HTML/CSS or any suitable interface
- Back End: Any suitable programming language

12. CONCLUSION

The Vehicle Parking Management System provides a simple way to manage
vehicle parking records. It helps maintain vehicle, driver, parking,
entry/exit, and payment information accurately.
